03 — Signature Feature

주인공 기능: 맞춤 식단 추천기

"먹어도 살 안 찌고, 영양이 고른 식단을 추천해줬으면 좋겠다"는 아이디어를 실제로 계산이 작동하는 기능으로 구현했습니다.

어떻게 작동하나요

1
목표 선택 — 근육 증가 / 체지방 감량 / 컨디션 유지 중 하나를 고릅니다.
2
오늘 운동 강도 선택 — 가볍게 / 보통 / 고강도 중 하나를 고릅니다.
3
목표 칼로리 · 단백질 자동 계산 — 선택 조합에 따라 오늘 필요한 kcal과 최소 단백질(g)을 계산합니다.
4
메뉴 6종과 매칭 — 스윗밸런스 메뉴 중 계산된 목표에 가장 가까운 2개를 밸런스 매칭 점수(0~100점)로 골라줍니다.
5
결과 시각화 — 매칭 점수 게이지, 단백질·탄수화물·지방 막대그래프, 추천 이유를 함께 보여줍니다. "운동한 만큼, 몸이 변합니다" 메시지로 마무리됩니다.
04 — Interview → Page

반영된 나의 답변

인터뷰에서 답한 5가지가 페이지 어디에, 어떻게 들어갔는지 정리했습니다.

질문답변반영 위치
1. 고객운동하는 사람전체 카피 톤, 제품 선정, 추천기 로직 모두 운동하는 사람 기준으로 설계
2. 첫 문장운동한 만큼 몸이 변한다히어로 헤드라인 "운동한 만큼, 몸은 정직하게 변합니다." + 추천기 결과 하단 요약 문구
3. 대표 제품닭가슴살 스테이크, 샐러드랩대표 제품 섹션 2개 카드로 소개, 추천기 데이터에도 포함
4. 아이디어 기능살 안 찌고 영양 고른 식단 제안페이지의 주인공 — 맞춤 식단 추천기 (목표·운동 강도 기반 실시간 계산)
5. 분위기신선한 초록 + 미니멀 화이트디자인 시스템의 Vital Green(#00614E) + Sunshine White(#FDFFE6) 베이스와 자연스럽게 일치, Seed Green을 유일한 포인트 컬러로 통일
